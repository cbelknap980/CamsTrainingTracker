# Change log

| 2026-11-17 | v1.4.0 | After the first leg day. Sets end on their own timer and are logged at target; the rest screen shows the set just done with four effort buttons (Easy, Solid, Hard, Maxed, stored as RPE 6/8/9/10) and tap-to-fix weight and reps. 5-second get-ready count before every set (amber screen, ticks, voice). Voice prompts for sets, rests and set-ups. Set time now comes from reps x per-exercise tempo with a pace bar; set-up time by equipment before each exercise's first set and a switch step inside finisher rounds. Work screen is green, rest is blue; exercise name much larger with 'Barbell · Set 3 of 4' under it; focus cues per exercise; Effort tile in plain words. Back and Pause buttons on the screen. Pre-session overview: session goal, every exercise with sets, reps, editable weight (rough estimates for free-weight accessories with no history) and estimated time. Install card on Home. 'Curl' is now 'Standing dumbbell curl'. Settings: voice and auto-advance toggles. |
| 2026-11-16 | v1.3.0 | End-of-session Review screen: every exercise with its sets (tap to correct), the engine's verdict (Up / Hold / Drop / Set) with reason, next weight and reps editable; overrides are tagged 'set by you'. Benchmarks table on Home for the 7 benchmark lifts: enter a set-of-5-with-2-left weight and targets update (90% in weeks 1-2), replacing the week-1 work-up for that lift. Log tab (was History) gains an Exercises view: every exercise's sets by date with RPE, e1RM, PR markers and an e1RM trend line. Engine lines now carry a verdict and reason. |
| 2026-11-16 | v1.2.0 | Session progress strip under the header: one segment per block sized by planned minutes and labelled with exercise names, filling as steps complete; status line with block n of N, steps, minutes left, projected finish and ahead/behind (Trim chip lives here now). Tap the strip for an overview sheet: every block with its exercises, set ticks (done/current/upcoming/skipped), weight, and minutes used vs planned. Set readout is now three tiles: Weight (amber), Reps, Effort; the rest screen's Up next uses the same tiles. Short exercise names added to plan.json. |
| 2026-11-16 | v1.1.1 | Service worker revalidates app files with the server (cache: no-cache) so a new publish shows on the next open instead of after GitHub Pages' 10-minute cache. |
